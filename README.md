# cricket99
> Making cricket easy to understand for fans of all levels.

Cricket99 is a fast, clean, and ad-free static website dedicated to breaking down cricket rules, gear maintenance, and tactical history into clear, simple guides.

## Site Structure
* **Homepage (`index.html`):** Recent posts and topic hubs.
* **Blog Posts (`blog-entry-1.html`):** Structured, mobile-friendly guides with quick answer summaries.
* **Categories:** Gear Guides, Rules & Basics, and History.

## Key Features
* ⚡ Ultra-fast loading built with clean HTML5 & CSS3
* 📱 100% responsive for mobile and desktop screens
* 🚫 Zero forced ads or popups
